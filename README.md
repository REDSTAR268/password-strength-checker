# 🔐 Password Strength Checker

A beginner-friendly Password Strength Checker built with **HTML, CSS, and JavaScript**.

This project helps users evaluate password strength based on several requirements and provides visual feedback.

## ✨ Features

- Check password strength.
- Show or hide the entered password.
- Check password requirements in real time.
- Display password strength levels: Weak, Medium, and Strong.
- Light Mode and Dark Mode.
- Responsive design for different screen sizes.

## 📋 Password Requirements

The checker evaluates passwords based on these five requirements:

- At least 10 characters.
- Contains at least one number.
- Contains at least one letter.
- Contains at least one special symbol.
- Contains at least one uppercase letter.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Use

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Enter a password to check its strength.
5. View the results and password requirements.

## 🎯 Project Goal

The goal of this project is to practise HTML, CSS, and JavaScript while learning about form handling, input validation, regular expressions, DOM manipulation, and event listeners.
